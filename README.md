# SBT Tracker apps

Installers for the SBT Sales Tracker. They contain no data: they open the company's live app, which needs a login.

- **Android:** download `SBT-Tracker.apk` from the latest release and install it (allow "install unknown apps" when asked).
- **Windows:** download `SBT-Tracker.exe` and run it. On first run it installs itself and adds a desktop / Start-menu icon. If Windows SmartScreen appears, click *More info -> Run anyway*.
- **iPhone:** open the app link in Safari -> Share -> *Add to Home Screen*.
